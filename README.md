# gogeom

平面几何小库：三次贝塞尔求值、离散采样（`Flatten`）、折线长度、多边形面积与内外判定，以及**曲线间最近距离**。

## 曲线间距离（`geom/distance.go`）

### 算法

1. **点到曲线**：距离平方写成参数函数 `f(s) = |C(s)-p|²`，求导得驻点方程
   `g(s) = (C(s)-p)·C'(s) = 0`（五次多项式）。在 Bernstein 基下做二项加权卷积
   得到 `g` 的系数，利用凸包性质递归二分隔离 `(0,1)` 内全部实根；
   比较各驻点与端点 `s=0,1` 处的 `f` 值，取最小。
2. **段到段**：交替投影迭代——固定 `t` 对 `s` 全局投影，再固定 `s` 对 `t` 全局投影。
   每个半步都取全局最小，距离序列单调不增且有下界 0，必然收敛。
   起点用 9×9 粗网格播种，避免落入非全局局部极小。
3. **曲线到曲线**：对所有段对求段间距离，取最小，结果记录最近点落在第几段。

### 收敛判据（自定）

同时满足以下两条即停：
- 距离相对下降量 `prev - d <= 1e-12 * max(1, prev)`
- 参数步长 `max(|Δs|, |Δt|) <= 1e-9`

**为什么够用**：单调不增序列的相邻下降量趋于 0 只是收敛的必要条件，可能停在
缓慢爬行的平台上；再加上参数本身也停止移动，说明 `(s,t)` 已落在驻点（或边界）上，
继续迭代只能在浮点误差内抖动，不可能再取得超过容差的改进。另设
`d <= 1e-13` 直接判交、200 步上限兜底。

### 两项独立验证（测试里分开验）

- **法向共线**（`TestNormalCollinear`）：最近点处连接向量 `w = PA - PB` 同时垂直于
  两条曲线的切向（参数在区间内部时），即两条法线都平行于 `w`。距离为零时 `w` 为零
  向量，条件平凡成立，跳过。
- **单调下降**（`TestDistanceMonotone`）：交替投影的距离历史逐步不增。

### 拦下的三种情形（报错并指出第几段）

| 情形 | 错误 | 示例信息 |
|---|---|---|
| 曲线重合（公共弧而非孤立交点） | `ErrCoincident` | `曲线A第0段与曲线B第0段重合` |
| 控制点退化（四点缩成一点） | `ErrDegenerate` | `曲线A第1段控制点退化` |
| 段数为零 | `ErrBadSegments` | `曲线A段数为0` |

## 跑法

```sh
go test ./geom/ -v          # 测试：五组样本 + 两项验证 + 三种拦截
go run ./cmd/distdemo       # 演示：打印五组样本的最近点对与收敛步数
```

## 五组样本实测结果

| 样本 | 最近距离 | 曲线A最近点 | 曲线B最近点 | 收敛步数 |
|---|---|---|---|---|
| 平行 | 1.000000000 | (0, 0) | (0, 1) | 2 |
| 相交 | 0.000000000 | (2, 0) | (2, 0) | 2 |
| 交叠 | 0.000000000 | (3, 0) | (3, 0) | 2 |
| 分叉 | 0.000000000 | (0, 0) | (0, 0) | 1 |
| 远离 | 8.062257748 | (3, 0) | (10, 4) | 2 |

样本定义在 `geom/samples.go`，演示与测试共用同一份，保证输出一致。
样本曲线接近直线，网格播种后一两次投影即收敛，步数小是正常结果。
